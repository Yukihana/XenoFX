Required:
EFC.Design package installation in startup project

Use Package Manager Console:
base command: Add-Migration <Migration-Name>
optional: -OutputDir <RelativeDirectoryPath>
may need to provide: `-project <project-with-dbcontext>`
may need to provide: `-startupproject <project-with-startup>` (if from a different project)

Convention:
Initial: shorthand
InitialCreate: first ever checkpoint, if applicable.
InitialBaseline: not historically, but the one used as first.

Note:
- one directory per dbcontext
- without specifying it'll occupy migrations root folder
- when dealing with multiple dbcontexts, use a subfolder outputdir under migrations.

Bypass for rebase/refresh database schema:
1. Delete existing EF_migrations table (and history) from the associated database.
2. Clear existing migrations
3. Run `Add-Migration InitialCreate` to set current state as initial.
4. Run once:
	Comment out the Up() and Down() methods in the migration file.
	(Or run `Update-Database -IgnoreChanges` to apply the migration without changes.)
	This ensures the checkpoint is registered without any changes.
5. Uncomment it for consistency. And a must for new deployments.
