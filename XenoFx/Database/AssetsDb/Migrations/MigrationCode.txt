1. Set main module executable as startup project
2. Open package manager console.
3. Set current project OR specify using `-project` (project containing the db context)
4. Enter:
Add-Migration InitialCreate -Context AssetsDbContext -OutputDir Database/AssetsDb/Migrations

Breakdown:

Command
MigrationName
-Context Value
-OutputDir Value
